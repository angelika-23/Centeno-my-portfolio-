ANGELIKA B. CENTENO — PORTFOLIO WEBSITE

HOW TO OPEN:
1. Extract the ZIP file.
2. Open the angelika_portfolio folder.
3. Double-click index.html.
4. The website will open in your browser.

EDITING:
- Edit index.html using VS Code or Notepad.
- Your activity images are inside the assets folder.
- Replace the contact placeholders with your real email and social links.
- The contact form is a front-end demo and does not send messages yet.
